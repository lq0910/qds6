# QDS6 连接文件夹分组

日期：2026-11-11；作者：lq。

## 操作方式

- 侧栏“新建分组”打开就地输入，支持中文名称、Enter 保存、Escape 或按钮取消。空名称、同区重复名称、控制字符及保留名称“未分组”提供就近错误提示，失败保留输入。
- 文件夹行显示展开箭头、开合文件夹图标、名称和连接数量。单击整行切换展开/收起；Tab 可聚焦，左方向键收起、右方向键展开，Enter / Space 切换。长名称省略显示，悬停可看完整名称及数量。
- 文件夹右侧“…”或右键菜单提供“在此分组新建连接”“重命名分组”“删除分组”。“未分组”是系统目录，不能重命名或删除。
- 删除确认展示分组名和受影响连接数。确认后成员移至“未分组”，保留配置、凭据引用和活动会话；取消不修改数据。
- 将连接拖到目标文件夹即可归组。目标高亮，成功后自动展开。也可通过连接的“…”或右键菜单选择“移动到分组”；当前归属有勾选且不能重复移动。
- 连接表单保留手工输入分组的能力，并新增已有分组选择菜单。手工填写“未分组”按系统未分组处理；选择相同项不会制造未保存提示。
- 搜索和收藏筛选临时展开命中的文件夹，显示“匹配数量 / 总数量”；清空筛选恢复原收起状态。新建文件夹后清除原筛选，避免新目录不可见。
- 空分组独立保留；服务器、数据库工作区各有目录，同名互不影响。当前为单层文件夹，不增加嵌套分组或自定义排序。

## 数据与任务边界

- SQLite 增量增加 `connection_groups`，按协议工作区回填原连接上的分组名称。配置结构和凭据格式不变；所有 SQLite 操作放后台。
- 重命名、删除以及成员归组在事务中完成，失败回滚。事务内读取最新配置，只变动分组字段，保留稳定 ID、认证、隧道和其他字段。
- 分组任务与连接保存、加载、恢复互斥；任务失败保留旧界面及输入。分组任务未完成时阻止关闭窗口，未提交的分组输入纳入关闭确认。
- 更改分组时只同步当前表单的分组基线，保留其他未保存字段；用户已自行修改的分组输入不被覆盖。活动服务器与数据库会话不重建、不自动重连。
- 连接保存与导入/恢复同步注册目录；恢复及本机快照回滚后同步刷新目录。现有导出格式仍只携带各连接的分组名；空目录和收起状态是本机目录信息，不新增到导出格式中。
