# 数据库对象菜单与导入导出备份

日期：2026-11-12；作者：lq。

## 已实现

- 数据库对象树常显纵向滚动条；右侧目录使用固定表头、常显横纵滚动条和完整视口约束。横向滚动可查看名称、模式、OID、所有者、引擎/表类型、估计行数、字节大小、主键、备注和对象类型。MySQL 不提供 PostgreSQL 的 OID/所有者列，详情显示“—”。行数是服务端统计估计值。
- 查询结果在结果分区底部保留独立的常显横向滚动条，支持横向滚轮和拖动到最后一列。
- 两处表目录共用右键菜单，目标以右键命中的表为准：打开、设计、表查询、重命名、复制、导入、导出、运行 SQL 文件、SQL 转储和刷新。
- 复制表支持结构和数据/仅结构，在相同模式下自动生成 `_copy`、`_copy_2` 等名称，复制字段、主键、索引、默认值、外键；身份/serial 默认序列与源表独立。触发器与访问权限不复制。
- 表级导出支持整表 UTF-8 CSV、Excel `.xlsx`、SQL 结构和数据/仅结构。读取独立只读事务快照，流式读取全部记录，不受结果页 10000 行上限、当前页或筛选条件影响。已有文件拒绝覆盖，失败清理半成品。
- CSV/Excel 导入支持 `.csv`、`.xlsx` 和 `.xls`；首行是字段名，按名称匹配，先展示前 100 行及目标表，再显式开始。只追加记录，使用单事务，失败全部回滚；不要求目标表有主键。
- SQL 文件向导显示目标连接、当前数据库、文件大小和执行行为，显式开始后执行。普通 UTF-8 SQL（不超过 5 MiB）可直接通过现有 SQL 服务执行；较大文件或 psql/DELIMITER 指令走官方数据库客户端。遇错停止并显示消息日志。
- 对象树顶部“数据库 · 库名”右键支持运行 SQL 文件、整库 SQL 备份、整库 SQL 导入/恢复。活动数据库连接的侧栏右键菜单也提供整库备份恢复入口；其他未连接配置的对应项禁用。
- 向导使用“常规 → 确认与预览 → 开始 → 消息日志”，保留查询草稿；修改类操作要求先处理表中未保存的数据/结构草稿。路径选择按向导代次回填，预览后选项改变必须重新预览。

## 文件与客户端约定

CSV 使用 UTF-8（导出含 BOM）；Excel 读首个工作表，导出 `.xlsx` 全部使用文本单元格，保留大整数、前导零并避免公式被执行。`\N` 表示 NULL，空字符串仍为空字符串；以反斜线开头的文本在导出时加倍，导入时还原。Excel 生成文件最多 1048575 条数据及一行表头；单元格超过 Excel 自身限制会明确报错。导入限制为 100000 行、文件及解码数据 64 MiB。自动身份/计算列和当前不支持的字段类型需要从导入文件移除；二进制列使用 SQL 文件恢复。

表级 PostgreSQL SQL 转储支持普通表和视图，保留字段、默认值、身份/serial、计算列、约束、索引和备注；分区、继承、RLS 表明确拒绝基础转储，建议使用官方 pg_dump。独立表依赖的 schema、类型及被引用表需已存在；不包含函数、触发器、授权等依赖对象，完整范围请使用整库备份。

整库备份恢复调用对应版本的 `pg_dump` / `psql` 或 `mysqldump` / `mysql`。优先使用向导填写的客户端目录，再查应用旁 `database-tools`、常见 Homebrew 安装目录和 PATH；无需把密码写进命令行，日志兜底脱敏。整库范围为连接配置中指定的一个数据库，包含官方工具支持的数据库对象，排除服务器级用户/角色；PostgreSQL 导出不包含 owner/ACL。目标为空库最容易恢复，向导不会自动删除已有同名对象。

PostgreSQL 整库恢复使用 ON_ERROR_STOP 和单事务；MySQL DDL 隐式提交，失败前可能已有部分语句生效，向导预览和错误日志会说明。官方客户端版本不兼容、缺失客户端或权限不足时显示实际错误，失败不报告备份成功。系统尚未安装 MySQL 客户端时需在向导配置其 bin 目录。
