# SFTP 系统文件拖入上传修复

日期：2026-11-24；作者：lq。

## 原因和改动

原有文件区只接收应用内部的 `FileDrag`，未接收 Finder 等系统文件管理器提供的 GPUI `ExternalPaths`，因此从系统文件夹拖入远程目录不会触发上传。

远程列表空白处现在接收系统路径并上传到当前目录；远程普通文件夹行、隐藏本地模式的远程目录树节点分别以落点文件夹为目标，并停止事件冒泡以免同时上传到父目录。拖入时显示落点高亮。本地列表不接收外部上传。

系统路径与内部拖放共用容量限制、任务去重、串行上传、进度和错误历史。文件属性读取、递归扫描、符号链接拒绝和 SFTP 网络传输继续在后台执行。同名文件覆盖、同名目录合并沿用既有传输服务。未连接、无效路径或队列超限给出明确提示。
