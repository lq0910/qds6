# 终端文本选区与复制修复

日期：2026-11-16；作者：lq。

## 问题与行为

终端原来仅处理鼠标点击聚焦，没有输出选区；`⌘C` 固定复制整个可见屏幕。

- 鼠标左键拖动选择局部输出并高亮，支持反向、跨行和历史输出。
- `⌘C` 和原生“编辑 → 复制”仅复制选中文字；没有选区时保留已有剪贴板。
- `⌘⇧C` 显式复制整个可见屏幕，`⌘V` 保持粘贴。
- 双击选词，三击选行；单击重新选择，输入或粘贴清除旧选区。
- 选区使用 Alacritty 原生网格坐标，中文宽字符和组合字符完整复制，终端软换行自动连接、硬换行保留。
- 鼠标拖出画布后松开仍会结束拖选；没有实现边缘自动滚屏，历史文字可先滚动到可见区域再选择。
