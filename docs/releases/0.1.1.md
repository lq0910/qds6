## QDS6 0.1.1 更新说明

2026-11-28 · macOS 内测

- 数据库新增 MySQL 和 PostgreSQL 表关系图。右键基础表即可查看引用方向、复合外键字段映射以及更新和删除规则，也可打开关联表结构。
- 新增快速打开（⌘K），可搜索已保存和最近使用的连接、远程目录书签及 SQL 收藏。
- SSH 终端可搜索当前屏幕及回滚内容，并从支持 OSC 7 的 Shell 定位到 SFTP 目录。修复终端选区和主题同步问题。
- SFTP 支持从 Finder 拖入文件，完善同名文件覆盖和失败任务重试。重试合并上传时会跳过上次已上传成功的文件。
- 新增按连接查看 SQL 历史和加密保存 SQL 草稿。生产连接默认关闭 SQL 历史。
- 支持预览并导入 OpenSSH 静态 Host 配置和单跳 ProxyJump，连接失败时会提示发生问题的阶段。

安装包支持 Apple Silicon 和 Intel Mac，最低系统版本为 macOS 14。Windows 版仍在开发计划中。
