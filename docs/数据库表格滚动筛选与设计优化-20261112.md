# 数据库表格滚动、筛选与设计优化

日期：2026-11-12；作者：lq。

## 交互调整

- 数据网格底部独立预留常显横向滚动条，支持滑块拖动和触控板横向滚动，表头与单元格共用横向偏移。字段名称、完整类型（含长度等）和数据库备注分三行显示；悬停可查看完整表头和单元格文本。
- 工作区、对象面板和对象列表限制绘制范围，修复长列表滚动后覆盖工具栏的问题。对象行保持固定内容高度，不因列表过长相互挤压。
- 筛选默认展示一条紧凑规则，“筛选与排序”展开多规则编辑。支持 AND / OR、包含、等于、不等于、大小比较、开头/结尾匹配及 NULL 判断；等于空字符串与 NULL 区分。回车或“应用”执行，“重置”清除筛选及排序并回到第一页。
- 多字段排序在服务器执行，最后追加未指定的主键作为稳定分页顺序。字段名按元数据校验，值用参数绑定，LIKE 特殊字符按字面量转义；每页仍最多 200 行。
- 设计表在表标签内展示字段列表、名称、类型、非空、主键、默认值及备注，并提供索引页。字段直接行内编辑，添加字段插入新行，支持预置类型选择及多行统一 SQL 预览；已执行结构清除本地草稿后通过刷新重新读取。后续交互与验证详见《表设计行内编辑与类型选择-20261112.md》。新增表保留独立工具栏入口。
- PostgreSQL 仅对变化的属性生成 ALTER / COMMENT 语句，多条变更使用事务包装；MySQL 生成完整字段定义，保留已有类型长度、排序规则和附加属性。生成列通过查询页编辑完整定义。生成 SQL 进入查询编辑器，保留原来的草稿替换确认，用户审阅后显式运行。
- 表数据标签右键支持“关闭 / 关闭其他选项卡 / 关闭右侧选项卡 / 全部关闭”。批量关闭按原标签实体识别，未保存数据统一确认；取消时保留全部目标标签及草稿。关闭范围为表标签，查询草稿仍独立保留。
- 每表独立保留筛选输入、排序、字段显示、设计输入和数据草稿；结构变化后按字段名重映射筛选/隐藏列，避免索引错位。
