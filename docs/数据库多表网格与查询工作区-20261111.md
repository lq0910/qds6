# 数据库多表网格与查询工作区

日期：2026-11-11；作者：lq。

本次为 Rust + GPUI Kit 原生工作区实现。保留工作树中已有的服务器、文件、迁移及安装脚本改动；未提交、未推送，未替换 `/Applications/QDS6.app`。

## 已实现

- 连接成功后后台自动读取表、视图和真实连接上下文，不执行 SQL 草稿。对象列表支持搜索、表/视图切换、刷新；对象栏与右侧工作区之间可拖动，宽度范围 150–500 逻辑像素。
- 默认右侧展示对象列表。双击左侧对象或右侧列表打开表；多张表各自保留分页、筛选、网格、字段显示、详情和未保存修改，重复打开切换已有标签。标签与对象选中身份同步。
- 顶部为新建查询、表、视图、表设计、CSV 导出和关闭连接。数据库会话标签也有关闭按钮；确认关闭清除对象、表标签和结果，释放会话回滚未提交事务，SQL 草稿保留在当前进程。活动后台任务期间禁止关闭。
- 表网格双击单元格直接编辑，Enter 结束输入；下方提供新增、删除/恢复、保存、取消、NULL、DEFAULT、刷新、分页。空字符串与 NULL 分离，未填写的新行字段使用服务端默认值。自动识别单列或复合主键，允许修改普通主键，身份/生成列只读。
- 保存前读取真实字段元数据，同一事务锁定原记录，核对原快照。冲突、重复键、类型或约束错误整批回滚；失败保留草稿并解除编辑锁。不自动重放写入；无主键、视图及不支持的主键类型只读，MySQL 写入限 InnoDB。
- 标签下方可按选择字段做文字包含筛选，参数绑定并转义 LIKE 通配符；每页 200 行，按主键稳定排序，多取一行判断下一页。有未保存修改时禁止刷新、分页、筛选覆盖草稿。
- 字段显示可以隐藏/恢复列，刷新 Kit 的列映射；详情显示真实字段类型、可空性、默认值、生成列、主键和索引。
- SQL 只在点击新建查询时出现在同一数据库工作区的查询标签中，左侧对象栏保留。查询栏显示真实连接/数据库/模式，支持运行选区或全文、停止、事务控制、复制、多结果集及 CSV。编辑器与结果区之间可拖动。
- 表设计入口保留新表、新增 TEXT 字段 SQL，并提供重命名表、清空表、删除表/视图、删除字段 SQL。生成到查询页后审阅并明确点击运行；替换已有修改的查询草稿前确认，并拒绝覆盖确认期间再次变化的内容。结构 SQL 执行成功后刷新对象目录。

## 边界

- 当前一个活动数据库会话支持多张表；连接另一数据库前先关闭当前连接，避免静默丢弃事务和草稿。查询标签目前复用一份会话内 SQL 草稿，不包含持久查询历史或多份查询文档管理。
- 这是参考 Navicat 的基础交互，完整图形化结构设计器、关联表编辑、外键向导、复杂组合过滤、全库数据导出尚未实现。CSV 导出当前页/当前查询结果；原始 SQL 结果仍只读。
- 二进制及部分特殊类型不做文本写入；修改值限 64 KiB。表浏览当前页解码限制 16 MiB；查询保留现有总 10000 行/16 MiB 与取消规则。
- 原生验收是测试平台的真实文字整形、鼠标键盘交互和 Metal 帧；确认弹窗通过标准 PromptResponse 的可点击测试视图验收。不能代替真人中文 IME、系统弹窗外观、正式安装包、干净机器或 Windows 验收。
