# 数据库滚轮与表设计直接保存

日期：2026-11-13；作者：lq。

## 行为

- 对象目录的横向容器不再把纵向滚轮转换为横向移动；纵向列表使用独立滚动轴。底部横向滚动条继续可拖动。
- 表设计“预览变更 SQL”改为“保存”，后台执行全部字段草稿，成功后读取最新结构和数据，保留当前设计标签，不创建或切换查询标签。
- PostgreSQL 保存使用独立事务，执行失败显式回滚；失败保留草稿。保存前核对字段快照，拒绝覆盖外部结构变化或混入手动事务。
- MySQL DDL 依照数据库的隐式提交规则执行，部分执行失败会提示核对结构；后续重试仍核对字段快照。
- DDL 后清理连接的预编译语句缓存，避免 PostgreSQL 在表列变化后刷新 SELECT * 时出现 0A000。
- 保存成功但后续读取失败时，禁止重复提交已执行的草稿，显示刷新入口。
- 查询页 BEGIN / COMMIT / ROLLBACK 改为“开始事务 / 提交事务 / 回滚事务”，并补充悬停说明。
