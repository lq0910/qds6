# 文件双列表与侧栏按钮优化

日期：2026-11-12；作者：lq。

## 当前交互

- 默认本地/远程双列表模式不显示目录树以及各侧内部的分隔条。仍可调整两个列表的宽度，以及终端和文件区的高度。
- 双击文件夹进入、上级返回、地址栏回车或刷新跳转。切换目录清理上一层选择和缓存，后台旧请求不能覆盖新目录。
- 工具栏提供「隐藏本地 / 显示本地」。隐藏后远程区域占满文件区，内部显示左侧远程目录树与右侧文件列表，树宽可拖动调整；显示本地后收起树，恢复本地/远程双列表。切换保留两侧路径、选择、滚动状态和传输队列；下载继续写入原本地目录，下载按钮及切换按钮的提示可查看目标路径。显示模式按服务器会话独立保存，不新增全局持久化偏好。
- 远程目录树从根目录保留当前路径层级，仅列文件夹，箭头展开/收起不导航，单击目录更新右侧列表。列表双击进入、上级、地址栏跳转同步树中高亮。展开按需后台加载，不跟随符号链接；读取失败可收起再展开重试，错误不覆盖文件传输提示。树缓存独立于列表导航，展开层级在模式切换后保留。
- 文件名列优先吸收额外宽度，其余属性保持固定宽度并可横向滚动。本地目录选择改用带提示的文件夹图标，避免最小窗口挤压上传按钮；仅隐藏文件的快捷入口放入列表空态。
- 连接列表侧栏的收放按钮改为 Kit 标签栏的前缀，共用背景、底线和垂直对齐，使用弱化图标并去掉常驻选中底色，保留悬停提示和点击区域。
- 保留多选、批量上传下载、对侧文件夹行/空白区域拖放、嵌套目录与空目录传输、拒绝覆盖及传输记录。

## 文件列表滚动修复与验证

日期：2026-11-12；作者：lq。

原外层 `overflow_x_scroll` 在 GPUI 中会将纵向滚轮映射成横向滚动。现改为裁切并保留横向偏移，使用纵向滚动输入层驱动虚拟列表；横向只通过底部滚动条手动调整。列表右侧增加常显纵向条（内容溢出时），滚动条固定在可见视口边缘，排除表头及底部横条区域，各预留 16px 操作空间，避免宽表格将纵向条带出屏幕或两条滚动条重叠。

- 开发构建通过，日志 `output/file-scroll-build-20261112.log`；应用全目标与全 feature Clippy 无警告，日志 `output/file-scroll-clippy-20261112.log`。
- 原生 GPUI/Metal + 回环 SSH/SFTP 专项通过，日志 `output/file-scroll-smoke-20261112.log`。只使用专用 `qds6-file-scroll-20261112` 容器及独立临时配置，测试后清理该容器。
- 创建并真实上传 80 个文件，在 1440×900 / 960×640 的本地与远程列表发送普通鼠标行滚轮和像素滚动，确认纵向偏移变化、横向不动，最后一项 `file-079.txt` 可见；滚到底后继续滚轮也不横移。
- 通过原生 MouseDown/Move/Up 事件拖动横条查看属性并拖回，拖动纵条到顶部及底部，核对首行和最后一行均可见。远程树模式同样验证纵向滚轮；已有目录导航、多选拖放、下载、错误恢复及侧栏回归通过。
- 已目视核对 `output/sidebar-files/scrollbars-1440.png`、`scrollbars-960.png`、`scrollbars-tree-960.png`，双轴滚动条位于列表边缘，底部文件可见。

- 开发构建通过：`cargo build -p qds6-app --offline`，日志 `output/remote-tree-build-20261112.log`。

- 真实原生 GPUI/Metal 与回环 SSH/SFTP 专项通过：`QDS6_FIXTURES=1 target/debug/examples/sidebar-files-smoke`，日志 `output/remote-tree-smoke-20261112.log`。仅连接专用 `qds6-remote-tree-20261112` 容器的 `127.0.0.1:22222`，独立临时配置与指纹，不连接业务服务器。
- 核对树中不出现普通文件；点击箭头后台加载下一层但不改变右侧当前目录；单击目录、上级返回、双击列表文件夹、地址栏真实回车均同步列表、路径和树中高亮。
- 回归原有多选、双向批量拖放与真实文件内容、嵌套/空目录、隐藏文件和错误恢复；隐藏本地后的下载按钮仍写入原本地目录，恢复本地后保留选择且不再显示远程树。
