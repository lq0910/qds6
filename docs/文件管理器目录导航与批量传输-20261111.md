# 文件管理器目录导航与批量传输

日期：2026-11-11；作者：lq。

针对实际使用中“目录与文件混在展开树内，不方便查看某一级和批量传输”的问题，本地、远程均改为目录导航树加当前目录详情列表。保留 Rust + GPUI Kit 原生实现。

## 交互

- 左侧目录树只显示文件夹。箭头展开/收起，单击目录定位右侧列表；右侧只显示当前目录直接子项，双击文件夹进入，点击「上级」返回。地址栏回车和刷新可直接跳转；导航过程保留已知祖先目录。
- 两侧标题处的文件夹按钮可独立收起目录树；树和列表之间可拖动调宽，详情底部常显横向滚动条。
- 单击单选；⌘/Ctrl 增减选择；Shift 连选；「全选」或列表焦点内的 ⌘A/Ctrl+A 选择当前层级全部可见项，Escape 清空。切换目录清空上一层选择；刷新或关闭隐藏文件显示会移除失效/不可见选择。
- 从任意已选行拖动整组选中项。放到对侧详情中的文件夹行或目录树节点，传入该目录；放到对侧空白区域，传入当前目录。按钮同样批量传入对侧当前目录，排队后路径冻结。
- 列表展示文件名、大小、类型、修改时间、POSIX 权限和用户/用户组。修改时间按本机时区显示；用户/组使用真实 UID/GID，未知属性显示「—」。SFTP v3 不提供账户名称，不把远程编号猜成本机账户名称。
- 多选时禁用单项重命名、权限、删除操作。符号链接不能批量传输，混选链接会明确阻止提交；单目录和队列各有 20000 项边界，不静默丢弃超出部分。传输沿用拒绝覆盖、串行队列、进度、取消和目录递归实现。

## 代码

- `crates/qds6-app/src/server_ui/files_ui.rs`：目录/当前路径状态、后台读取、批量队列与双侧布局。
- `crates/qds6-app/src/server_ui/files_ui/explorer.rs`：目录树、虚拟化详情列表、多选、键盘和批量拖放；文件属性格式化及边界单测。
- `crates/qds6-services/src/sftp.rs`：保留服务端 mtime、UID、GID。
- `crates/qds6-app/src/server_ui/files_ui/smoke.rs`：隔离真实 SSH/SFTP 原生交互与内容校验。
- `crates/qds6-app/src/services_ui/smoke.rs`：旧综合验收的文件部分同步至“进入目录/当前目录目标”语义。
