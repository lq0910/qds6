# QDS6 图标与品牌规范

> 功能：应用品牌、界面图标库与资源接入约定；日期：2026-11-10；作者：lq。

## 应用图标

品牌以字母 Q 和连接端点组合，表达「连接，从此简单」。深青底承托白色 Q，薄荷绿尾笔形成连接线及端点。不在图形内放入 QDS6 全称，保证小尺寸辨识。

| 资源 | 路径 | 用途 |
| --- | --- | --- |
| 矢量母版 | `assets/brand/qds6.svg` | 后续尺寸与宣传图生成源 |
| 单色标识 | `assets/brand/qds6-mark.svg` | GPUI 标题栏，使用主题前景色 |
| PNG | `assets/brand/png/qds6-{size}.png` | 16、24、32、48、64、128、256、512、1024 px，透明背景 |
| macOS | `assets/brand/qds6.icns` | 后续 `.app` 包 `CFBundleIconFile` 资源 |
| Windows | `assets/brand/qds6.ico` | 后续 EXE / 安装包图标资源 |
| 设计样张 | `assets/brand/preview.png` | 品牌、尺寸检查与 32 个界面图标样张 |

主色为 Midnight `#122C34`、Porcelain `#F2FAF7`、Mint `#54D9B1`。PNG 保留透明安全边距，不额外叠加系统外部投影。彩色应用图标使用 GPUI `img`，单色标识使用 `Icon`，避免将彩色 SVG 放入单色遮罩管线。

本轮已将品牌接入欢迎页和标题栏。ICNS / ICO 是已生成的打包输入资源；项目尚未通过本轮工作配置原生安装打包、Dock 图标或 Windows EXE 图标，不将文件生成记录为安装验收。

## 图标库选择

统一使用 **GPUI Kit 随附的 Lucide**。GPUI 是绘制框架，图标目录与 `Icon` 组件由本项目选用的 Kit 提供，无需引入 WebView、JavaScript 图标包或字体图标。

以 `Cargo.toml` 锁定的 Kit 提交 `ab7bd640021e062094cb4fd1e15fc6b465ec6a47` 为依据：

- `gpui_kit::assets::IconName`：1,830 个图标名，包含 1,818 个 Lucide 1.43.0 图标及 12 个 Kit 保留图标。
- `gpui_kit::component::IconName`：旧兼容枚举，业务开发统一使用前者，以免缺少数据库等图标。
- 默认 `Assets`：只嵌入 101 个组件 SVG。枚举中有名字，不代表默认资源源中有 SVG。
- `icon_assets!`：按需嵌入指定图标；本项目当前选择 33 个常用图标（含组件对象树新增的 ChevronDown），与默认组件资源及品牌资源组合为 `AppAssets`。原设计样张保留首轮 32 个图标。
- `AllAssets`：可显式注册整个目录；本项目使用按需方案，后续在 `WorkbenchIcons` 清单添加图标即可。

来源：[Kit assets 官方说明](https://github.com/longbridge/gpui-kit/tree/ab7bd640021e062094cb4fd1e15fc6b465ec6a47/crates/assets)、[Lucide](https://lucide.dev/)。上述数量是锁定版本的目录事实，不代表未来版本数量。

## 使用方式

资源实现：`crates/qds6-app/src/assets.rs`。主应用和原生 UI 验收均注册 `AppAssets`，避免生产与测试使用不同资源源。资源在编译时嵌入，运行时无需联网或访问用户目录。

```rust
// 功能：使用统一 Lucide 图标，图标需同时列入 WorkbenchIcons 清单；时间：2026-11-10；作者：lq。
use crate::assets::UiIcon;
use gpui_kit::component::{Icon, button::Button};

let search_icon = Icon::new(UiIcon::Search);
let save_button = Button::new("save-example")
    .icon(UiIcon::Save)
    .label("保存");
```

| 场景 | 图标 |
| --- | --- |
| SSH / SFTP / 数据库 | `Terminal` / `Folder` / `Database` |
| 连接、SQL、工作区标签 | `Server` / `FileCode` / `PanelLeft` |
| 搜索、新建、保存、收藏 | `Search` / `Plus` / `Save` / `Star` |
| 导入、导出、上传、下载 | `Upload` / `Download`，由操作文案区分方向 |
| 凭据、安全、连接、断开 | `KeyRound` / `Lock` / `Plug` / `Unplug` |
| 表格、运行、复制、刷新、设置、删除 | `Table2` / `Play` / `Copy` / `RefreshCw` / `Settings` / `Trash` |
| 主题 | `Sun` / `Moon` |
| 状态、展开、更多 | `Check` / `TriangleAlert` / `LoaderCircle` / `Circle` / `ChevronRight` / `Ellipsis` |
| 网络与终端页 | `Network` / `SquareTerminal` |

沿用 Lucide 的 24 × 24 坐标及 2 px 设计描边，实际界面常用 16 / 20 px；保持同一控件内图标尺寸一致。颜色继承主题，状态结合文字表达，交互按钮保留文本或无障碍名称，不以图标代替状态文案。

## 导出与许可

开发机需要 Python 3、Pillow 与 `rsvg-convert`。导出程序不在应用运行时调用。

```sh
# 功能：从 SVG 母版重建 PNG、ICO 和 ICNS；时间：2026-11-10；作者：lq。
python3 scripts/export-icons.py

# 功能：附带生成完整 Lucide 样张；参数指向锁定 Kit 的本地图标目录；时间：2026-11-10；作者：lq。
python3 scripts/export-icons.py --kit-icons /path/to/gpui-kit/crates/assets/assets/icons
```

QDS6 自有品牌源码作者为 lq，遵循本项目许可。Lucide 图标为 ISC，部分继承 Feather 的图标适用 MIT；原始完整声明保存在 `third-party/LICENSE-LUCIDE`，不得改署为 lq。发布包必须带上该声明；程序内嵌图标不免除许可保留义务。设计预览中的 Lucide 样张同样受该许可约束。
