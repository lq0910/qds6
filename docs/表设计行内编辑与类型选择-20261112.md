# 表设计行内编辑与类型选择

日期：2026-11-12；作者：lq。

## 交互

参考 Navicat 的字段列表编辑方式，移除列表下方独立的字段表单。字段名称、类型、长度、小数位、非空、默认值 SQL 表达式、备注均可直接在对应行修改。

- 顶部和列表末尾的“添加字段”直接插入新行，滚动到新行并聚焦名称，支持连续添加和同时修改多个字段。
- 类型单元格同时支持输入与下拉菜单。PostgreSQL 预置 27 种常用类型，MySQL 预置 30 种，包括字符、数值、时间、JSON 等；枚举和数据库自定义类型可以直接输入完整定义。选中字符类型自动填入常用长度，选中 numeric / decimal 自动填入初始精度，切换类型会清理旧参数。
- 从已有字段类型中拆出长度和小数位，保留时区及 unsigned 后缀；无法解析的枚举或自定义定义原样保留。只修改备注时不会改写原字段类型。
- 删除已有字段先标记，行内按钮变为“恢复”；新行删除后不生成 SQL。“撤销修改”恢复当前表的全部字段快照。
- 表头固定，字段列表独立纵向滚动，底部常显横向滚动条；两个滚动方向独立，横向滚轮不会顺带移动纵向列表。
- 结构草稿参与标签脏标记、关闭单表、批量关闭与断开连接提示，返回数据页及切换标签保留草稿。存在结构草稿时阻止数据编辑、刷新、筛选和翻页覆盖草稿。

## 变更应用

“预览变更 SQL”汇总全部行的新增、修改和删除，复用现有查询草稿替换确认。PostgreSQL 多语句使用事务包装；MySQL 保留已有排序规则和附加属性。重复字段名、相互占用的重命名、非法长度/精度、生成列修改会提示错误。

预览不会自动执行。用户在查询页运行后，返回设计页“撤销修改”清除已应用的本地草稿，再“刷新”重新读取结构。主键仍显示已有定义，索引页仍提供查看；主键、外键及复杂约束通过查询页处理。
