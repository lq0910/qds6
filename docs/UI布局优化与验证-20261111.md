# QDS6 原生工作区与双栏文件树

日期：2026-11-11；作者：lq。

## 交互与布局

- 左侧导航区分“服务器”和“数据库”。SSH 和 SFTP 属于同一服务器工作区，数据库连接、SQL 和结果在数据库工作区内操作。
- SSH 连接后默认上方终端、下方本地和远程文件树同屏。上下、左右分隔条均可拖动；可单独收起文件区。终端查找按需展开。
- 每个服务器标签拥有独立终端、文件树、远程编辑器、草稿、传输队列和状态。同名不同连接配置不共用状态；切换功能区保留会话。
- 两侧文件夹按需后台读取，保留层级和展开状态，支持键盘方向键。单击选择，箭头或双击展开/收起；远程文本双击打开编辑器。
- 左侧本地文件或文件夹拖到右侧目录上传，反向拖动下载。目录行精确接收至该目录，空白处接收至该侧选中目录（选中文件时为父目录），没有选中项时为树根。拖动预览显示方向和名称，目标目录高亮。
- 两侧“上传 / 下载”按钮使用选中源项及对侧目标目录，悬停显示目标路径。移除手工填写上传源/下载目标的共用文件路径输入框。
- 本地可通过系统“选择目录”、地址栏回车、上级或刷新切换树根；远程地址成功读取后显示真实绝对路径。
- 每台服务器串行传输，最多等待 100 项。底部显示字节进度、等待数、取消当前及清空等待；传输记录菜单列出等待任务和最近 20 条结果。成功后刷新目标目录。
- 文件夹传输保留嵌套结构和空目录；预检限制 64 层、10000 项，不跟随符号链接。默认拒绝覆盖已有目标，失败或取消清理本次临时内容；清理失败显示路径。
- 删除保留确认，确认操作绑定原选中路径。重命名目录在父目录执行，避免错误移动至自身。
