## 平台范围

最终平台范围为 macOS 与 Windows，实施顺序为 Mac M0–M3 → Mac 主要功能基本落地 → W0 Windows 适配；Mac M4 按独立平台证据推进。T401–T412 先验收 Mac 子项，Windows 和跨平台子项保留至 W0。Linux 不提供首版安装包，也不作为 M0–M4 的退出条件；保留未来扩展所需的平台边界。

连接迁移与备份的格式和字段要求见[连接导入导出与备份规范](./连接导入导出与备份规范-20261110.md)。
