# QDS6 当前改动汇总与第 04 次内部打包

日期：2026-11-11；作者：lq。

## 本次提交内容

相对基线 `aa2fd5799593ef36a8733000c69dc0c3bd27e79d`：

- 界面主题增加「自动」，跟随原生系统外观通知；设置页保留三态选择，标题栏按浅色 → 深色 → 自动循环。外观订阅独立于连接表单，重建表单不会丢失监听，手动主题不受系统通知覆盖。
- 默认启动窗口由 1440×900 改为居中 1200×780，最小尺寸仍为 960×640。
- SQLite 初始化改用立即事务，避免连接与偏好并发初始化时延迟事务升级互锁；增加并发读取和三态主题持久化兼容测试。
- 外部导入及恢复页面增加原生单文件选择入口，保留路径输入。选择新文件清空旧预览，取消保留原状态，忙碌时禁用；增加平台回调及布局回归。
- FinalShell 接受 `conection_type: 100` 和无代理 `proxy_id` 标记，继续拒绝有效代理和非 SSH 类型；私钥引用提示重新选择，不复制来源密码或读取来源私钥。无可导入项时直接展示跳过原因，覆盖预览、隔离恢复和重复导入测试。
- 打包脚本支持显式内部构建号并写入 Info.plist 与构建清单。本次补齐分组安装历史记录、导入修复记录、自动主题记录，并更新使用说明中的分组、SFTP、导入和主题操作。

分组和 SFTP 的主要实现已包含在基线提交中，本次仅整理相关说明及已有安装记录，不重复计为本次新增实现。
