# 内测打包与缓存清理

功能说明：固定日常内测版本与构建编号，覆盖同名安装包，阶段性清理调试缓存。日期：2026-11-12；作者：lq。

- 当前内测版本沿用 `Cargo.toml` 的 `0.1.0`，打包脚本默认构建编号固定为当前最新包的 `2026111203`，日常测试不递增。正式调整时再修改 Cargo 版本或显式传入 `--build-number`。
- 执行 `python3 scripts/package-macos.py`，默认输出仍为 `output/release/0.1.0-macos-arm64-internal/`，APP、DMG、ZIP 名称固定；新产物签名与归档验证成功后替换旧目录，不新增日期目录。
- `build-manifest.json` 新增 `packaged_at_utc`，源码指纹纳入 `scripts/`。即使版本与编号相同，仍可通过时间、源码及二进制摘要识别实际内容。
- 不在每次打包后自动删除缓存，避免日常测试反复全量编译；磁盘紧张或阶段工作结束时再清理 `target/debug`。

本次确认无编译及调试目录程序运行后，清空 QDS6、Mini Office、QCode、SAB 的 `target/debug`，保留 Cargo 锁文件。实测磁盘可用空间增加 50,702,618,624 字节，约 50.7 GB；详细记录位于 `output/debug-cache-cleanup-20261112.json`。各项目源码、配置、凭据、数据库、发行缓存和安装包均保留；未识别用途的 TAR、ZIP 未清理。

验证：打包脚本语法及命令帮助通过；当前保留的 QDS6 DMG、ZIP 的 SHA-256 与清单一致。此次没有重新编译或生成安装包，也未进行桌面运行、真实服务或安装验收。
