# QDS6 0.1.0 · Mac 内部测试版

连接，从此简单。 / Connections, simplified.\
终端、文件与数据库，一个工作台。 / Terminals, files, and databases. One workspace.

日期：2026-11-11；作者：lq。

本包为 Apple Silicon（arm64）原生应用，使用 Rust + GPUI Kit，无 WebView。安装最低版本设置为 macOS 14；实际运行及服务验收环境为 macOS 27.0.1 / M4 Pro。Intel Mac、其他 macOS 版本和 Windows 尚未验收。

## 安装与首次启动

打开 DMG，将 QDS6.app 拖到「应用程序」，再从该目录打开。也可解压 ZIP 后复制 QDS6.app。应用已作 ad-hoc 本地签名，未使用 Developer ID，未公证；系统可能阻止来自网络的首次启动，请在 macOS「隐私与安全性」中核对来源后允许。无需安装 Rust、Homebrew、OpenSSL 或数据库客户端。

普通连接配置保存在 `~/Library/Application Support/QDS6/connections.sqlite3`；密码及草稿密钥保存在 macOS Keychain 的 QDS6 服务项。首次访问或内部版本升级后，系统可能询问 Keychain 访问授权；拒绝授权不会改写已有密钥，输入密码后仍可连接，但无法恢复已加密草稿。不要删除仍需恢复草稿的密钥。

更新时退出 QDS6，再替换应用。卸载只删除应用，配置和 Keychain 条目会保留。彻底清理前先导出所需备份，并自行清理上述数据目录及对应 Keychain 项；其他应用数据不在清理范围。

## 连接和终端

1. 点击「新建连接」，选择 SSH、SFTP、MySQL 或 PostgreSQL，填写名称、主机、端口与用户名。按名称、主机、分组搜索；支持收藏和生产环境标记。
2. 密码留空时使用已保存凭据；新密码保存进 Keychain。私钥路径需为本机实际文件，口令填在密码栏；Agent 模式使用当前进程的 `SSH_AUTH_SOCK`。从 Finder 启动时需确保系统登录会话提供该变量。
3. 「保存连接」只保存配置；「连接」才联网。首次 SSH 连接需通过可信渠道核对 SHA-256 指纹，变化时拒绝连接；记录位于数据目录 `known-hosts.json`，只在核实服务端变更后手工移除对应旧记录。
4. 单跳跳板/数据库隧道填写已保存 SSH 连接名称或 UUID，名称有歧义时用 UUID。跳板自身不能再配置跳板。隧道与终端、SFTP 独立持有，关闭终端不会切断其他资源。
5. SSH 最多 10 个终端标签，可移动、关闭及并列分屏。支持宽字符、Vim/tmux、PTY 尺寸更新、粘贴和 5000 行回滚。⌘C 复制当前可见屏幕，⌘V 粘贴，⌘± 缩放；搜索仅覆盖当前可见屏幕。断线后需手动重新连接，不重放命令。

删除连接会先确认并检查隧道依赖；活动会话保持原连接，Keychain 引用保留供已有本机快照回滚。原有密码引用的主动清理由用户在 Keychain 中管理。

### 文件夹分组

侧栏点击「新建分组」输入名称，Enter 保存、Escape 取消。分组像文件夹一样展开/收起，显示连接数量并记住收起状态。分组的「…」或右键菜单可在组内新建连接、重命名或删除；空分组也会保留。删除需确认，其中连接会移到「未分组」，配置和活动会话保留。

将连接拖到目标分组即可移动，也可通过连接的「…」或右键菜单选择「移动到分组」。连接表单中的下拉菜单可选择已有分组。搜索会临时展开命中的分组，清空搜索后恢复原状态；服务器与数据库的同名分组互不影响。导出配置包含各连接的分组名，空分组和收起状态仅保存在本机。

## SFTP 和远程编辑

SSH 连接后默认上方终端、下方本地和远程两个文件列表同屏；可拖动分隔条调整大小或单独收起文件区。每侧只列出当前目录的直接子项，双击文件夹逐级进入，通过「上级」返回。文件区工具栏的「隐藏本地」切换为远程目录树与远程文件列表：左侧树只显示文件夹，箭头展开/收起，单击文件夹切换右侧列表；树和列表之间可拖动调宽。目录树从远程根目录保留路径层级，按需后台读取，并与地址栏、上级和双击进入同步定位。「显示本地」恢复本地/远程两个列表并收起远程树，切换时保留两侧路径、选择、滚动和传输队列。隐藏本地时，下载仍使用原本地目录，可通过下载按钮的悬停提示确认目标。每个服务器标签有独立文件状态与传输队列。

本地可用标题旁的文件夹图标（选择本地目录）、地址栏、上级或刷新切换目录。列表支持单击单选、⌘（Windows 使用 Ctrl）增减选择、Shift 连选；「全选」或列表获得焦点后的 ⌘A / Ctrl+A 只选择当前层级可见项目，Escape 清空选择，切换目录会清空上一层选择。拖动任意已选行会传输整组选中项：放到对侧文件夹行传入该文件夹，放到空白处传入对侧当前目录；上传/下载按钮同样使用整组选中项与对侧当前目录。支持有界目录递归、空文件夹、进度、取消、等待队列和最近传输记录；不跟随符号链接，不支持续传或自动重试。默认拒绝覆盖同名目标。远程「…」提供创建目录、重命名、权限和删除，删除操作需要确认。

两侧详情列表显示文件名、大小、类型、修改时间、权限、用户/用户组，文件名优先使用额外宽度，属性列可通过底部横向滚动条手动拖动查看；鼠标滚轮控制纵向浏览文件，不转换成横向移动。列表右侧常显可拖动纵向滚动条（内容超过视口时），两条滚动条固定在可见区域边缘，不随宽表格横移。修改时间以本机时区显示；用户和用户组显示实际 UID/GID，缺失属性显示「—」，不猜测名称。权限使用 POSIX rwx 格式；选中多项时单项重命名、权限和删除按钮禁用。

远程普通 UTF-8 文本双击可进入 Kit 编辑器；上限 5 MiB、100000 行、单行 64 KiB。二进制、非 UTF-8 和符号链接拒绝编辑，不自动猜测编码。支持 JSON、Shell、SQL、TOML、YAML 语法高亮及 Kit 查找/替换和撤销；CRLF 文件保存时保留换行符。

修改后自动用 Keychain 密钥加密缓存到 `drafts/`。重新连接相同已保存连接时恢复当前文档草稿；每个连接仅保留一个当前文档。缓存失败会明确提示仅保留本次会话，请复制重要内容。保存成功清理草稿；「放弃并关闭」明确丢弃缓存。

保存前核对内容、权限及属主；上传到同目录排他临时文件后再次比较，并要求服务器支持 OpenSSH `posix-rename@openssh.com`。缺少能力、权限/属主无法保留、上传失败或发现冲突时不主动截断原文件。此流程存在最终比较与重命名之间的远端并发窗口，不提供跨客户端 CAS 保证。ACL、扩展属性、硬链接语义及目录父路径替换保护不在本版保证范围。

## 数据库

已用 MySQL 8.4 / PostgreSQL 17 验证。直连默认严格 TLS，支持 CA 文件并校验主机名；自签 CA 需显式选择。SSH 隧道当前不能覆盖 SQLx 的原目标 TLS 名称，因此严格 TLS 与隧道组合会明确拒绝；可选择直连 TLS，或明确关闭隧道内数据库 TLS（SSH 通道仍加密）。

以下数据库交互对应 2026-11-11 最新源码，尚未替换本机安装包；验证见 [数据库工作区记录](../数据库多表网格与查询工作区-20261111.md)。

连接后自动显示表和视图，拖动对象栏右边缘调整宽度。双击表打开数据，多张表在内部标签切换；单击标签关闭按钮关闭表，有未保存修改时会询问。数据库连接可以点顶部「关闭连接」或会话标签的 × 关闭，未提交事务回滚。

双击数据单元格直接输入，Enter 完成输入。底部「+」新增、「删除」标记删除或恢复、「保存」一次提交本表全部修改、「×」取消本表草稿。NULL 表示空值，空字符串仍是普通文本；新增行未填写字段使用数据库默认值，也可点 DEFAULT 恢复默认。主键由系统识别，支持复合主键；保存失败保留输入，修正后再保存。其他人修改过相同记录时拒绝覆盖，本次保存全部回滚。

表上方选择筛选字段并输入包含的文字，点筛选；「清除」恢复未筛选第一页。每页 200 行，底部翻页。有未保存修改时先保存或取消再翻页、刷新或筛选。「字段显示」控制列，「表详情」显示字段、默认值、主键和索引。视图、无可用主键及不支持的类型只读，MySQL 写入限 InnoDB。CSV 导出当前页，先保存或取消草稿后再导出。

点击「新建查询」才打开 SQL 查询标签，左侧对象栏和其他表标签继续保留。输入完整 SQL 或选择一段后运行，原样发送、不自动补 LIMIT；支持停止和同连接 BEGIN/COMMIT/ROLLBACK。编辑器与结果分隔线可拖动。SQL 草稿仅保留当前会话，可复制另存；每次执行总结果最多 10000 行或 16 MiB，多结果集分别查看，超过上限调用服务器取消。查询结果只读，可排序和导出 CSV；排序按显示文本进行。CSV 空字段表示 NULL，引号空字符串表示空文本，二进制按十六进制导出。

「表设计」可生成新表、新增字段、重命名、清空、删除等基础 SQL，到查询页审阅后明确运行。完整图形化设计器和持久查询历史尚未实现。手动事务期间拒绝另起网格保存事务；修改过 autocommit 或调用过程后需重新连接使用网格保存。一次仅打开一个数据库连接，切换数据库前先关闭当前连接。网络错误会停用旧会话，需要重连，不自动重试写入。

## 导入、导出、备份和回滚

在「导入与备份」切换到「从其他工具导入」或「恢复与回滚」，点击「选择文件…」打开系统文件选择器；也可粘贴文件绝对路径。取消选择不会改变原路径或预览。导出时仍填写目标文件绝对路径。

- 支持 PuTTY `.reg`、FinalShell JSON 单文件/数组、FileZilla SFTP XML、Navicat MySQL/Pg XML 的保守导入预览；只解析数据，不执行命令、注册表或读取导入路径指向的私钥。FinalShell 兼容已验证的 DES 保存密码格式；Navicat MySQL/PostgreSQL 兼容 XML `Password` 字段中的旧 Blowfish、AES-CBC 格式。账号和可识别密码一并导入，预览逐条显示密码状态与总数；确认后才写入 macOS Keychain，取消不写入。密码不在界面、报告或普通配置中显示。
- Navicat 明确设置 `SSL=false/0` 或 `UseSSL=false/0` 时沿用关闭 TLS，缺失开关时仍保留严格 TLS；启用但尚未映射的 SSH/TLS 配置会明确跳过。数据库名优先读取 `Database`，兼容旧字段 `InitialDatabase`。旧版已导入连接可重新选择相同文件，使用默认的“合并”导入，确认后更新 TLS 并补全数据库名；精确匹配的旧连接保留原 ID，不新增重复项。重新连接后生效。
- FinalShell 已验证 `conection_type: 100`、`proxy_id: "0"` 的 SSH 文件；有效代理引用仍跳过，私钥认证需重新选择密钥且不会将密码字段误作私钥口令。不支持或未保存的密码提示补填。Navicat 真实来源版本导出矩阵仍未验收，不承诺所有版本、主密码保护或机器绑定 AES-GCM 字段、加密归档；`.ncx` 仅在内容为受支持 XML 时解析。其他格式仍为合成样例验证。旧格式不含认证校验，能解码不等于服务器登录已验证，导入不会自动连接业务服务器。
- 「导出配置」生成无密码的 JSON；「加密备份」使用至少 8 字符口令，可选包含已保存密码/私钥口令。不包含私钥文件、证书文件、查询历史、主机信任和编辑草稿。更换 Mac 后需重新选择本地资源路径、核对主机指纹。
- 加密采用 Argon2id（64 MiB / 3 次 / 1 通道）+ XChaCha20-Poly1305，输入文件上限 16 MiB、连接上限 10000。请另行保管备份口令，应用无法找回。
- 先「读取并预览恢复」，核对后选择按 ID 合并或替换；确认后先生成数据目录 `before-restore-*.json` 本机快照，再事务写入。错误口令、篡改、未知 schema 或无效引用不会写入配置。恢复不自动连接，已有会话需重新连接才使用新配置。
- 本机快照保留原 Keychain 引用但不含密码。需要回滚时选择快照文件，点击「回滚所选本机快照…」并确认；回滚前再次留存当前状态。快照不是可移植备份，仅适合同一 Mac 及仍有效的原 Keychain 引用。

## 设置与关于

点击最左侧栏底部「设置」进入独立设置页。可选择浅色/深色/自动主题、10–24 px 终端字号、SQL 自动换行；更改成功后自动保存到本机，重启保留。「自动」跟随系统外观，手动浅色/深色不受系统切换影响。标题栏快捷按钮按浅色 → 深色 → 自动 → 浅色循环，按钮文字表示下一次切换目标。字号应用到现有和新建终端，SQL 设置不改写查询文本。设置单独保存在本地 SQLite 的 `preferences` 表，不写入密码或连接导出。

默认启动窗口居中显示，尺寸为 1200×780，仍可调整大小；最小尺寸为 960×640。

「终端配色」提供两套浅色（晴空、暖纸）和两套深色（深海、墨林）。默认开启「跟随软件深浅色」，随软件手动切换或系统自动外观变化联动，晴空/深海、暖纸/墨林分别成对切换。点击具体配色预览会固定该配色；重新勾选联动即可恢复自动。切换同时更新当前终端和之后新建的终端，不清屏、不重连、不重置临时字号。默认文字、ANSI16、光标、搜索及输入法组合文本使用同一色表，命令显式指定的真彩色与扩展256色保留原值。

连接列表可通过标签栏左端的侧栏按钮收起/展开；收起后也可点击左侧「服务器」或「数据库」找回对应列表。仅含隐藏项的目录会提示隐藏数量，点击「显示隐藏文件」即可查看，不再把过滤后的目录显示为“空文件夹”。终端内容四周增加留白。

「版本与更新」显示当前构建版本，点击「检查更新」查询 `lq0910/qds6` 的 GitHub 正式 Releases。检查有超时与结果提示，未找到公开正式发布时不会显示“已经最新”；发现新版后可打开发布页下载，退出应用后手工替换。启动时不自动联网检查，不自动下载或安装。

「关于 QDS6」显示“非人类程序员出品”、QQ：960661824（可复制）、公众号二维码和开源仓库入口。二维码随应用离线内嵌。点击服务器或数据库入口返回业务工作区，已有连接及本次会话的草稿继续保留。

## 验收范围

本版具有真实服务与原生 Metal 自动化记录，是首个 Mac 内部可用包。真人中文输入法、跨显示器缩放、VoiceOver、干净机器安装升级、公证、全部异常服务和长期并发运行尚待专项验收；Windows 延后。本版不代表计划全部 M0–M4 复选项已完成。

精确依赖和许可位于应用「显示包内容 → Contents/Resources/ThirdParty」，构建信息在 `build-manifest.json`。四个旧依赖未附许可原文或旧源不可读，已明确标注标准许可补充并附原始源码；公开分发前仍需完整许可证复核。
