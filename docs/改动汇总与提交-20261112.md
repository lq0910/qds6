# 数据库与文件管理改动汇总

日期：2026-11-12；作者：lq。

## 数据库

- 增加 AND / OR 多条件筛选、11 种比较运算及多字段排序；字段校验、参数绑定及 LIKE 转义，主键补充稳定分页顺序。
- 数据表头展示完整类型与字段备注；固定底部横向滚动条，修复对象列表长内容覆盖工具栏问题。
- 增加表内设计页、字段行内编辑、类型预置、长度与精度、非空、默认值和备注编辑，支持新增、删除、恢复及批量 SQL 预览。
- PostgreSQL 按变化属性生成语句，MySQL 保留完整定义中的排序规则及附加属性；预览后由用户在查询页显式执行。
- 每表保留筛选、排序和结构草稿；关闭、断开及批量关闭时确认未保存修改；增加索引查看及标签右键关闭菜单。

## 文件管理与工作区

- 默认使用本地/远程双列表；隐藏本地后显示远程目录树与列表，保留路径、选择及传输状态。
- 远程树按需后台加载，支持展开、导航、高亮同步和失败重试；旧目录请求不能覆盖新导航。
- 修复普通纵向滚轮误触横移，增加固定在视口边缘的双轴滚动条，优化窄窗口按钮和文件名列空间。
- 将侧栏收放按钮融入 Kit 标签栏，统一背景、底线及垂直对齐。
- 补充数据库 SQL、原生交互及隔离服务专项验证代码和说明。
