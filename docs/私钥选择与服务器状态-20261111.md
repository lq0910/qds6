# 私钥选择与服务器基本状态

日期：2026-11-11；作者：lq。

私钥路径支持原生单文件浏览，取消保留原路径；中文和空格路径直接填回。选择器打开后切换表单，返回结果不写入另一个连接。私钥文件不复制到配置或安装包，认证仍沿用系统凭据库中的私钥口令。

服务器连接后默认展示可收起的左侧状态栏：连接地址与复制、运行时间、1/5/15 分钟负载、CPU、内存、交换空间、CPU 前五进程、网卡切换及最近四十次流量采样。采集仅适用于支持 `/proc` 和只读 shell 命令的 Linux；不安装程序、不申请提权。进程只采集命令名，不采集命令参数；进程 CPU 为 `ps` 的平均占用。内存使用量扣除 MemAvailable（旧内核用空闲和缓存估算），无交换空间显示未启用。

状态使用第三条独立 SSH 连接及独立后台线程；终端与 SFTP 保留原连接。每次采集完成后等待三秒，SSH 操作超时四秒，文本结果上限 128 KiB。CPU 和流量使用两次采样的计数差，首次显示采样中；接口重置或重启不生成负速率。失败停止继续采集，保留并明确标注旧数据，重新连接可恢复。监控生命周期随服务器标签，断开标签释放轮询和隧道引用。
